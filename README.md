# Roxonic GitHub Pages site

This repository hosts the official GitHub Pages site for Roxonic Limited.

## Local preview

Open `index.html` in a browser, or run a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Because this repository is named `roxoniclimited.github.io`, GitHub Pages will publish the site automatically from the root of the `main` branch.

## Files

- `index.html` – homepage markup
- `styles.css` – site styling
- `script.js` – mobile menu and footer year behavior

## Customization

Update the content in `index.html` and the colors in `styles.css` to match your branding as needed.
